# 搭建初始工作环境 (Initial Workspace Setup)

当需要为一个新项目搭建初始环境时，请执行以下标准流程：

1. **确定技术栈并讨论**:
   - 确认项目所需的编程语言及框架（前端和后端）。
   - 如果用户有偏好（如“后端偏向Python”），针对性地推荐常用的依赖和架构。

2. **创建本地Git仓库**
   - 将项目本地文件夹初始化为Git仓库，用于全流程版本控制。

3. **建立环境隔离**:
   - 为项目建立本地虚拟环境或包管理空间（例如 Python 的 `venv`，Node.js 的 `package.json`，或 Dockerfile）。
   - 激活环境以便后续安装和执行。

4. **安装常用依赖**:
   - 根据选定的语言/框架，安装最常用的基础依赖包（例如 Web 框架、ORM/数据库驱动、环境变量解析、API 客户端等）。

5. **记录工作日志**:
   - 严格遵循 `logs.md` 的规范，将环境搭建的完成情况、确立的技术栈等信息追加记录到当天的 `log.md` 文件中。
