## What to build
建立基础的数据储存方案，并在界面上实现单个日期下的普通日程“增、删、改、查”。
这是一个端到端的垂直切片，完成后用户可以直接通过前端 UI 输入日程，保存到本地数据库，并在当天的列表中即时看到新增的日程记录。

## Acceptance criteria
- [ ] 决定并实现本地数据存储方案（如 SQLite, JSON）。
- [ ] 构建基本的前端页面骨架，包含用于添加新日程的表单（标题、类别、起止时间、描述）。
- [ ] 日程添加成功后，列表能立即更新。
- [ ] 提供日程项的编辑和删除按钮，并实现对应的功能和二次确认机制。
- [ ] 日程在应用重启后依然持久化显示。

## Blocked by
None - can start immediately
