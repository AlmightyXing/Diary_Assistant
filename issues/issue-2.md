## What to build
开发系统底层进程（如通过原生 Node.js 插件或 Python 脚本获取前台活动窗口名称），并在主 UI 中提供一个隐私设置面板来维护“白名单”。
系统必须只能累加统计白名单内的应用活跃时间。

## Acceptance criteria
- [ ] 编写能够周期性获取当前系统前台窗口名称的后台服务。
- [ ] 在系统首次启动或个人设置页，提供一个白名单勾选界面。
- [ ] 后台服务根据用户勾选的白名单进行过滤，只记录在名单内的应用的聚焦时间。
- [ ] 在 UI 上能提供一个简单的测试看板或控制台打印，展示当前追踪到的应用时间总和，以验证功能闭环。

## Blocked by
None - can start immediately
