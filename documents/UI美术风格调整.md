# UI美术风格调整及部分功能修正

## 语言表现

所有的界面语言均默认使用中文，除非我明文指定（如导航栏标题）

## 侧边导航栏

### 标题

- 导航栏顶部标题应为“Dairy Assistant”
- 标题下方版本计数不需要“END_SYS_”的前缀

### 导航栏

- 导航按钮应当仅有图标，无文字
- 导航栏的宽度应当只比图标略宽
- 导航栏按钮被选中时，导航栏背景应当为 #FFFF00荧光黄的高亮，而非白色高亮 + 在右侧显示一个小方块
- 导航栏底部不需要“启动游戏”按钮
- 导航栏应有6个导航按钮，分别对应 `data/` 中的文件：
    - 日程创建 - `Doc.png`
    - 日程模板 - `Template.png`
    - 日程日历 - `Calendar.png`
    - 健康终端 - `Clock.png`
    - 日志生成 - `Upload.png`
    - 个人中心 - `Setting.png`

## 主界面

### 页面设计

- 窗口不要用纯黑色宽实线边框，也不要用纯黑色的投影
- 整体的背景不要出现网格线，保持纯净
- 窗口应采用无边框，靠本身的填色与背景作出区分
- 窗口的标题采用浅灰色，窗口底部可以使用类似的粉、蓝纯色小方块点缀

### 日程创建

- 添加记录功能中应当包含日程类型的选择，日程类型包含以下内容：
    - 工作
    - 学习
    - 娱乐
    - 运动
    - 其他

### 健康计时

- 健康计时页面应当居中并排展示两个窗口，分别为久坐计时和用眼提醒
- 健康计时应以"mm 分 ss 秒"的形式倒计时，精度到秒即可
- 倒计时的提醒应当发给Windows系统通知， 而非仅仅在界面上弹出对话框
