# UI 美术设计框架与重构计划：终末地工业机能风

通过对您提供的三张参考图（`M9A-UI`、`终末地-导航栏`、`终末地-信息展示`）进行解构，我们提炼出一套兼顾**高效信息展示布局**与**极简硬核机能美学**的设计框架。

## 核心设计语言 (Design Language)
**“重工业、高对比、去圆角化、信息层级极其鲜明”**

### 1. 色彩系统 (Color Palette)
摒弃了传统 UI 的柔和色调和过渡，采用极高对比度的“黑白灰+荧光点缀”方案：
- **底色 (Base)**: 纯白 (`#FFFFFF`) 与 冷灰 (`#F0F0F0`) 穿插，作为背景和信息容器。
- **文字与强调色 (Ink & Highlight)**: 极黑 (`#111111`) 用于主标题与边框。
- **主视觉点缀 (Primary Accent)**: 终末地标志性的**高亮荧光黄** (`#E5FF00` 或 `#FAFF00`)，用于当前高亮状态、极其重要的按钮或色块分割。
- **辅助点缀 (Secondary Accent)**: CMYK 风格的品红 (`#FF00FF`) 或 青色 (`#00FFFF`) 小色块，作为角标或装饰性“定位准星”元素。

### 2. 布局架构 (Layout Structure) - *继承自 M9A*
- **全局布局**: 左右分栏结构。左侧为极简垂直导航条，右侧为主工作区面板。
- **导航栏 (Sidebar)**: 
  - 图标采用**粗线条、几何切割、模板镂空风格 (Stencil)**。
  - 选中状态不再使用底色块，而是使用**粗壮的左侧实心黑/黄线段**，以及图标反白/变黑的极致高对比变化。
  - 底部可放置类似参考图中的“危险斜条纹”按钮（如：前往游戏/启动生成）。
- **内容面板 (Dashboard Cards)**:
  - 采用模块化的卡片排列，按信息块聚集（如：今日日程卡片、健康监控终端卡片、日记生成日志卡片）。

### 3. 组件与控件美学 (Components Aesthetics)
- **卡片与边框**: **彻底告别圆角 (0px Border Radius)**。使用硬朗的 1px 或 2px 纯黑实线边框，搭配不带任何羽化模糊的“硬阴影”(`box-shadow: 4px 4px 0px #000`)。
- **排版字体 (Typography)**:
  - 标题采用特粗无衬线体（如 `Inter Black` 或全局系统黑体），并且在标题前加入机能风标识符，例如：`// SCHEDULE` 或 `AIC 集成日程系统`。
  - 数据、时间、计时器严格使用**等宽字体 (Monospace)**，营造“终端仪表盘”的技术感。
- **背景与修饰**:
  - 主按钮背景可引入细密的**斜线阴影 (Hazard Stripes)** 纹理。
  - 面板空白处偶尔点缀微小的“点阵网格”或“4x4 方块阵列”图形，以增加工业蓝图的精密感。

## 实施路线图 (Proposed Changes)

如果按照此框架重构，我们需要对 `frontend` 进行以下深度改造：

### 第一步：基础设计系统搭建 (Design System)
- 创建 `frontend/src/index.css`，定义全局 CSS Variables（颜色、间距、字体）。
- 引入等宽字体与粗体字体栈。

### 第二步：组件化拆分 (Componentization)
目前的 `App.tsx` 过于庞大，将拆分为：
- `components/Sidebar.tsx` (机能风左侧边栏)
- `components/Card.tsx` (硬边框、硬阴影的容器组件)
- `components/Button.tsx` (包含斜条纹背景和高对比度反转的交互按钮)

### 第三步：功能模块套壳重构 (Module Refactoring)
- **日程管理视图**: 改造为两栏或网格卡片，左侧是任务列表，右侧是编辑表单。时间戳呈现为终端输出样式。
- **健康监控面板**: 设计为一个“工业仪表盘”，数值使用大号等宽字体实时跳动。
- **日记生成视图**: 采用类似命令行日志 (Console Log) 的从下往上打印的动效。
