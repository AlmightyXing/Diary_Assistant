# Diary Assistant (智能日程日记助手)

Diary Assistant 是一款集成了日程管理、健康监控以及 AI 辅助生成日记功能的桌面端效率工具。它致力于将您在电脑前度过的每一天进行无感量化，并通过大语言模型（如 DeepSeek/OpenAI）自动将这些碎片化的日程与活动总结为有温度的日记。

## 🌟 核心功能 (Features)

- **📅 高效日程管理**：
  - 提供日历视图，支持日程的增删改查。
  - 支持“模板 -> 实例”的流转体系，可以设置固定模板并每天自动生成当天日程。
- **🤖 AI 自动生成日记**：
  - 基于您的日程安排和实际应用使用时长，AI 将为您自动撰写当天的日记草稿。
  - 支持自定义填入您专属的大模型 API Key。
  - 拥有完善的生命周期管理（草稿 -> 待确认 -> 定稿）。
- **⏱️ 健康倒计时与白名单监控**：
  - 基于底层 `pywin32` 捕获 Windows 前台活动窗口，统计软件使用时长。
  - 严格的隐私控制，仅对用户在个人中心配置的“白名单应用”进行时长追踪。
  - 内置“久坐”与“用眼”双重防沉迷死计时提醒，保护您的身体健康。
- **🖥️ 桌面悬浮小组件 (Widget)**：
  - 无边框透明桌面挂件，实时展示核心日程和倒计时进度。
  - 支持鼠标穿透防误触，支持一键唤醒主界面。
- **💼 纯绿色免安装 (Folder-based Portable App)**：
  - 拒绝流氓注册表与冗余缓存。
  - 前后端高度集成封装，所有生成数据均保存在根目录下的 `data` 文件夹内。
  - 解压即用，拷贝即走。

## 🛠️ 技术栈 (Tech Stack)

- **前端架构**：`Electron` + `React` + `Vite` + `TypeScript`
- **后端架构**：`Python` + `FastAPI` + `SQLite` + `PyInstaller` (打包)
- **底层支持**：`pywin32` (系统状态监控)

## 📦 如何使用 (Usage)

本应用已采用绿色版（Portable）打包方案。

1. 下载/克隆本仓库（或进入 `frontend/dist_electron/win-unpacked/` 目录）。
2. 双击 `DiaryAs.exe` 即可启动应用主程序。
3. 应用运行中生成的所有持久化数据、用户配置以及 SQLite 数据库文件均会存放在执行目录的 `data` 文件夹中。

## 🛡️ 隐私声明

您的所有日记文本与统计数据仅保存在本地 `data` 文件夹内的 JSON 及 SQLite 数据库中。
在调用大模型接口进行日记生成时，只有当前配置的公开日程及授权的统计时长会被发送至云端 API。应用绝不会在未经授权的情况下私自收集您的后台隐私数据。
