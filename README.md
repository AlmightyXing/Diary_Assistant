# Diary Assistant (智能日程日记助手)

Diary Assistant 是一款集成了日程管理、健康监控以及 AI 辅助生成日记功能的桌面端效率工具。它致力于将您在电脑前度过的每一天进行无感量化，并通过大语言模型（如 DeepSeek/OpenAI）自动将这些碎片化的日程与活动总结为有温度的专属日记。

## 🌟 核心功能 (Features)

- **🤖 AI 智能生成日记 (深度定制版)**：
  - **丰富的文风定制**：支持在生成前选择【天气】、【心情滤镜】（开心、低落等）、【行文风格】（常规、活泼、严肃、报告等）以及【内容详略】（简略、详细、重点罗列）。
  - **日程与应用全覆盖**：基于您填写的日程及备注、当天的白名单应用真实使用时长，AI 将化身您的贴身记录员为您写日记。
  - **自动定时运转**：支持配置夜间自动生成时间（如 23:00），到点自动触发大模型写日记。如果网络不畅，也会贴心地降级生成一份本地保底的 Markdown 统计报告。
  - **支持历史补写**：随时点击日历上过去的任意一天，AI 都能精准匹配对应日期为您补充记录。

- **⏱️ 健康防沉迷与应用时序统计**：
  - **智能白名单监控**：自动拉取系统已安装应用，仅对用户在个人中心勾选的“白名单应用”进行时长追踪，支持超过 60s/60Min 的自适应时长展示转换。
  - **抗休眠倒计时**：内置“久坐”与“用眼”防沉迷死计时提醒。底层结合了系统休眠检测（Sleep Detection），在电脑休眠时自动挂起，唤醒后自适应重置，绝不错误弹窗。
  - **强力提醒**：倒计时结束时，会在后台静默创建全屏透明窗口触发“闪屏 + 提示音效”，为您强制护眼。

- **📅 高效日程管理**：
  - 提供直观的日历视图，支持日程的增删改查与备注附加。
  - 支持“模板 -> 实例”的流转体系，可以设置每日重复的固定模板，全自动装载当天日程。

- **🖥️ 桌面双极客小组件 (Dual Widgets)**：
  - 彻底解耦的桌面悬浮体系：分为专注倒计时的**健康小组件**与专注任务的**日程小组件**。
  - 均支持无边框透明渲染、自由拖拽位置记忆（独立存储）以及鼠标穿透防误触功能。

- **💼 纯绿色免安装 (Folder-based Portable)**：
  - 拒绝流氓注册表与冗余缓存，完全绿色的架构。
  - 所有生成数据（包括 SQLite 数据库、系统配置、窗口坐标记录）均保存在根目录或同一级的 `data` / `logs` 文件夹内。解压即用，拷贝即走。

## 🛠️ 技术栈 (Tech Stack)

- **前端架构**：`Electron` + `React` + `Vite` + `TypeScript`
- **后端架构**：`Python` + `FastAPI` + `SQLite` + `PyInstaller` (打包)
- **底层支持**：`pywin32` (系统前台状态捕获与休眠探测)

## 📦 如何使用 (Usage)

本应用已采用绿色版（Portable）架构设计：

1. 下载/克隆本仓库并完成编译（或进入 `frontend/dist_electron/win-unpacked/` 等打包输出目录）。
2. 双击 `DiaryAssistant.exe` 即可一键启动前端与 Python 守护进程。
3. 进入设置（或个人中心）填入您专属的大模型 API-Key，并在日历中添加几项日程。
4. 应用运行中生成的所有持久化数据、用户配置均会存放在应用执行目录中。

## 🛡️ 隐私声明

您的所有日记文本与系统级统计数据仅保存在本地的 JSON 及 SQLite 数据库中。
在调用大模型接口进行日记生成时，**仅有**当前日期对应的“公开日程”、“白名单应用的时长”以及“您的定制风格偏好”会被加密发送至云端大模型 API。应用绝不会在未经授权的情况下私自收集您的后台隐私数据或监控无关应用。
